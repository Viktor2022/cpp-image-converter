## Image Converter

Разработка универсального конвертера изображений с поддержкой форматов BMP, PPM и JPEG. Проект включает создание библиотеки **ImgLib** для работы с различными форматами изображений.

### Технологии и инструменты

- **C++** с современными стандартами
- **Система сборки** CMake
- **Работа с бинарными данными**
- **Обработка изображений**

### Основные форматы

**Поддерживаемые форматы:**

- **BMP** (Windows Bitmap)
- **PPM** (Portable Pixmap)
- **JPEG** (сжатое изображение)

### Архитектура системы

**Компоненты проекта:**

- **Библиотека ImgLib** для работы с изображениями
- **Система конвертации** между форматами
- **Модуль обработки** заголовков файлов
- **Механизм работы** с пиксельными данными

### Функционал

**Базовые возможности:**

- Конвертация между форматами
- Чтение и запись изображений
- Обработка метаданных
- Работа с пиксельными данными

**Особенности реализации:**

- Поддержка формата **BGR24** без сжатия
- Корректная обработка padding'ов
- Работа с заголовками файлов

### Технические детали

**Работа с BMP форматом:**

- Обработка заголовка файла
- Управление padding'ами
- Корректная запись данных
- Поддержка специфического порядка пикселей (BGR)

**Ключевые алгоритмы:**

- Вычисление отступов
- Преобразование форматов
- Обработка ошибок
- Валидация данных

### Результаты

- Высокая скорость конвертации
- Корректная обработка всех форматов
- Надежная работа с данными
- Отсутствие потерь при конвертации
